# portfolio-tracker

Трекер портфеля акций — статический сайт без сборки и без сервера. Вы вносите сделки,
сайт считает текущую стоимость, прибыль и убыток и строит графики. Только учёт —
никаких рекомендаций купить или продать.

## Что умеет

- **Сделки:** тикер, дата, покупка/продажа, количество (шт.), цена, комиссия
  (в рублях или в процентах от суммы — `0,05%`). Сделки можно изменять и удалять.
  Продажа больше, чем есть в портфеле на эту дату, не принимается.
- **Итоги:** текущая стоимость; прибыль/убыток в рублях и процентах — нереализованная,
  реализованная и общая — по каждой бумаге и по портфелю; сумма комиссий.
- **Доли бумаг** — кольцевая диаграмма (до 6 секторов, остальное — «Прочие»).
- **История стоимости** — график стоимости и чистых вложений по дням с периодами
  1М / 3М / 6М / 1Г / Всё и таблица значений на конец каждого месяца.
- **Цены** — с MOEX ISS; если API недоступен или бумаги там нет — ручной ввод.
- **Хранение** — только в браузере (`localStorage`), ничего не уходит на сервер.
- **Дивиденды и купоны** — по данным MOEX ISS: календарь будущих выплат по вашим бумагам
  (по месяцам) и список полученных; налог 13 % / 15 % / без налога; выплаты можно исключить
  и добавить вручную. Колонка «Выплаты» в позициях и «итог с выплатами».
- **Доходность и индекс МосБиржи** — график доходности портфеля в сравнении с IMOEX за тот же
  период (1М / 3М / 6М / 1Г / Всё), с выплатами или без.
- **Импорт сделок из отчёта брокера (CSV)** — сайт сам находит строку заголовков и угадывает
  столбцы, а вы видите и можете поправить сопоставление: что дата, что тикер, где цена или сумма,
  комиссии брокера и биржи, какие значения считать покупкой и продажей. Перед импортом —
  предпросмотр, номера строк с ошибками и пропуск уже внесённых сделок. Сопоставление
  запоминается для следующих отчётов того же вида.
- **CSV-экспорт:** сделки, позиции, история стоимости, дивиденды и купоны.
- Светлая и тёмная тема, адаптивная вёрстка для телефона.

## Запуск

Сборка не нужна.

1. **GitHub Pages (через GitHub Actions).** Один раз в репозитории: Settings → Pages →
   Build and deployment → **Source: GitHub Actions**. После этого каждое изменение ветки `main`
   проверяется тестами и публикуется workflow `.github/workflows/pages.yml`. Адрес сайта:
   `https://<логин>.github.io/portfolio-tracker/` (точная ссылка — в Settings → Pages и во вкладке Actions).
2. **На Windows без установки чего-либо:** Code → Download ZIP, распакуйте архив и дважды
   щёлкните `index.html` — сайт откроется в браузере. Котировки MOEX загружаются и так.
3. **Локальный сервер:** установите Node.js 18+ с https://nodejs.org, в папке проекта выполните
   `npm start` и откройте http://localhost:8080.

Данные привязаны к адресу сайта и браузеру: на другом устройстве или по другому адресу
их не будет. Для переноса и резервной копии используйте «Экспорт CSV → Сделки» и «Импорт сделок».

Сохранённые данные прошлой версии читаются без изменений: новые поля (ручные выплаты,
исключённые выплаты, ставка налога) добавлены в ту же запись `portfolio-tracker:data:v1`.

## Откуда цены

Бесплатный публичный API Московской биржи [MOEX ISS](https://iss.moex.com) без ключа,
данные с задержкой до 15 минут. Поддерживается фондовый рынок «акции»
(`engine=stock`, `market=shares`): акции, ETF и БПИФ в рублях.

| Что | Запрос |
|---|---|
| Основной режим торгов бумаги | `/iss/securities/{тикер}.json?iss.only=boards` |
| Текущие цены | `/iss/engines/stock/markets/shares/boards/{режим}/securities.json?securities=…` |
| Дневные цены закрытия | `/iss/engines/stock/markets/shares/boards/{режим}/securities/{тикер}/candles.json?interval=24` |
| Дивиденды акции | `/iss/securities/{тикер}/dividends.json` |
| Купоны облигации | `/iss/statistics/engines/stock/markets/bonds/bondization/{код}.json?iss.only=coupons` |
| Индекс IMOEX | `/iss/engines/stock/markets/index/boards/SNDX/securities/IMOEX/candles.json?interval=24` |

Текущая цена — последняя сделка (`LAST`), а вне торгов — текущая или официальная цена
закрытия. Режим торгов кэшируется на неделю, история цен и индекса догружается только за
недостающие дни, дивиденды и купоны обновляются раз в 12 часов.

Порядок выбора цены для бумаги (источник подписан в таблице позиций):

1. цена, введённая вручную (кнопка у цены → «Сохранить»; «Брать с MOEX» отменяет её);
2. свежая котировка MOEX;
3. последняя сохранённая котировка MOEX — с датой, если сейчас API не отвечает;
4. цена последней сделки — с предупреждением и предложением ввести цену вручную.

Облигации, валютные бумаги и иностранные акции через API не оцениваются — для них
используется ручная цена (для облигации — в рублях за штуку). Купоны облигаций при этом
загружаются с MOEX: тикером облигации служит её код на бирже (обычно ISIN, например `SU26238RMFS4`).

## Как считается

- **Средняя цена** — себестоимость позиции (покупки с комиссиями) / количество.
  При продаже себестоимость списывается по средней цене.
- **Нереализованная прибыль/убыток** = стоимость позиции − себестоимость; % — к себестоимости.
- **Реализованная** = выручка от продаж − комиссии − списанная себестоимость.
- **Итого** = текущая стоимость + выручка от продаж − все покупки с комиссиями;
  % — к сумме всех покупок. Эта величина не зависит от метода списания (средняя/FIFO).
- **Чистые вложения** на графике = покупки с комиссиями − выручка от продаж на дату.
  Разрыв между линиями стоимости и вложений — прибыль/убыток на эту дату.
- Стоимость на прошлую дату — по цене закрытия MOEX (в выходные — по последней),
  сегодня — по текущей цене. Если истории котировок нет, используются цены сделок.
- **Дивиденды и купоны.** Выплата начисляется на бумаги, которые были в портфеле на дату
  закрытия реестра, с учётом расчётов Т+1: сделка должна быть заключена не позже рабочего дня
  перед этой датой (до 31.07.2023 — Т+2 для акций и Т+0 для облигаций). Праздники биржи не
  учитываются. Будущие выплаты считаются на текущее количество бумаг.
- Дата выплаты дивиденда биржей не публикуется — она оценивается как 10 рабочих дней после
  даты реестра (помечена «≈»). Выплата считается полученной, когда эта дата прошла.
- Налог — выбранная ставка от суммы выплаты. Если брокер зачислил другую сумму, нажмите
  «Не учитывать» и добавьте фактическую сумму вручную («+ Выплата вручную»).
- **Итог с выплатами** = прибыль/убыток всего + полученные выплаты после налога.
  Налог с прибыли от продаж и уплаченный при покупке облигаций НКД не учитываются.
- **Доходность портфеля** для сравнения с IMOEX — взвешенная по времени: пополнения и продажи
  не считаются доходом. Доходность дня = (стоимость на конец + выплаты + продажи − стоимость
  на начало − покупки) / (стоимость на начало + покупки); дневные доходности перемножаются.
  Покупки считаются сделанными в начале дня. Обе линии начинаются с 0 % в начале периода.
- **IMOEX** — ценовой индекс, дивиденды в него не входят. Поэтому по умолчанию выплаты в
  доходность портфеля не включены; галочка «Учитывать дивиденды и купоны» включает их.

## Импорт отчёта брокера

1. Сохраните отчёт о сделках в формате CSV (в Excel: «Файл → Сохранить как → CSV»).
   Файлы `.xlsx`, `.html` и `.pdf` нужно сначала сохранить как CSV.
2. Нажмите «Импорт сделок» и выберите файл.
3. Проверьте сопоставление: строка с названиями столбцов, столбцы даты, тикера, количества,
   цены (или суммы сделки), комиссий и операции. Если столбца операции нет, направление
   определяется по знаку количества (минус — продажа).
4. Для каждого значения в столбце операции выберите «Покупка», «Продажа» или «Пропустить»
   (например, переводы бумаг или дивиденды в общем отчёте).
5. Посмотрите предпросмотр и нажмите «Импортировать N сделок».

Строки «Итого», шапка отчёта и пустые строки пропускаются. Дата может быть со временем
(`15.01.2025 10:23:45`). Продажа без предшествующей покупки не импортируется — сайт покажет,
какая именно.

## Формат CSV

Экспорт рассчитан на Excel с русской локалью: разделитель `;`, десятичная запятая, UTF-8 с BOM.

```
Дата;Тикер;Операция;Количество;Цена;Комиссия
2025-01-15;SBER;Покупка;100;270,5;13,53
2025-06-02;SBER;Продажа;40;310;6,2
```

Импорт понимает разделители `;`, `,` и табуляцию, кодировки UTF-8 и Windows-1251,
даты `ГГГГ-ММ-ДД` и `ДД.ММ.ГГГГ`, русские и английские заголовки в любом порядке.
Экспорт сделок этого сайта импортируется без правок.

## Структура

```
index.html        разметка
css/style.css     стили, светлая и тёмная тема
js/format.js      форматирование и разбор чисел и дат
js/portfolio.js   учёт: позиции, прибыль/убыток, история стоимости, доходность и сравнение с индексом
js/income.js      дивиденды и купоны: кому положена выплата, налог, календарь
js/csv.js         экспорт CSV, импорт с сопоставлением столбцов
js/moex.js        клиент MOEX ISS
js/charts.js      SVG-графики: кольцевая диаграмма и линия стоимости
js/app.js         интерфейс, хранение, обновление цен
tests/            юнит-тесты (node --test)
.github/workflows test.yml — тесты на Node 18/20/22; pages.yml — публикация на GitHub Pages
```

## Тесты

```
npm test
```

Нужен Node.js 18+, зависимостей нет. Тесты покрывают расчёты позиций, дивидендов и купонов,
доходности и сравнения с индексом, импорт CSV и разбор ответов MOEX ISS (с подменой сети).
На GitHub они запускаются автоматически при каждом push и pull request.
