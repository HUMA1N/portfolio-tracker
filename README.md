# portfolio-tracker

Трекер портфеля акций — статический сайт без сборки и без сервера. Вы вносите сделки,
сайт считает текущую стоимость, прибыль и убыток и строит графики. Только учёт —
никаких рекомендаций купить или продать.

## Что умеет

- **Сделки:** тикер, дата, покупка/продажа, количество (шт.), цена, комиссия
  (в рублях или в процентах от суммы — `0,05%`). Сделки можно изменять и удалять.
  Продажа больше, чем есть в портфеле на эту дату, не принимается.
- **Итоги:** текущая стоимость; прибыль/убыток в рублях и процентах — нереализованная,
  реализованная и общая — по каждой бумаге и по портфелю; сумма комиссий.
- **Доли бумаг** — кольцевая диаграмма (до 6 секторов, остальное — «Прочие»).
- **История стоимости** — график стоимости и чистых вложений по дням с периодами
  1М / 3М / 6М / 1Г / Всё и таблица значений на конец каждого месяца.
- **Цены** — с MOEX ISS; если API недоступен или бумаги там нет — ручной ввод.
- **Хранение** — только в браузере (`localStorage`), ничего не уходит на сервер.
- **CSV:** экспорт сделок, позиций и истории стоимости; импорт сделок (замена или добавление).
- Светлая и тёмная тема, адаптивная вёрстка для телефона.

## Запуск

Сборка не нужна. Варианты:

1. **GitHub Pages:** Settings → Pages → Build and deployment → Deploy from a branch →
   ветка `main`, папка `/ (root)`. Сайт откроется по адресу `https://<логин>.github.io/portfolio-tracker/`.
2. **Локально:** `npm start` (поднимет `http-server` на http://localhost:8080) или любой
   статический сервер в корне репозитория. Можно открыть `index.html` и напрямую из папки.

Данные привязаны к адресу сайта и браузеру: на другом устройстве или по другому адресу
их не будет. Для переноса и резервной копии используйте «Экспорт CSV → Сделки» и «Импорт CSV».

## Откуда цены

Бесплатный публичный API Московской биржи [MOEX ISS](https://iss.moex.com) без ключа,
данные с задержкой до 15 минут. Поддерживается фондовый рынок «акции»
(`engine=stock`, `market=shares`): акции, ETF и БПИФ в рублях.

| Что | Запрос |
|---|---|
| Основной режим торгов бумаги | `/iss/securities/{тикер}.json?iss.only=boards` |
| Текущие цены | `/iss/engines/stock/markets/shares/boards/{режим}/securities.json?securities=…` |
| Дневные цены закрытия | `/iss/engines/stock/markets/shares/boards/{режим}/securities/{тикер}/candles.json?interval=24` |

Текущая цена — последняя сделка (`LAST`), а вне торгов — текущая или официальная цена
закрытия. Режим торгов кэшируется на неделю, история цен догружается только за недостающие дни.

Порядок выбора цены для бумаги (источник подписан в таблице позиций):

1. цена, введённая вручную (кнопка у цены → «Сохранить»; «Брать с MOEX» отменяет её);
2. свежая котировка MOEX;
3. последняя сохранённая котировка MOEX — с датой, если сейчас API не отвечает;
4. цена последней сделки — с предупреждением и предложением ввести цену вручную.

Облигации, валютные бумаги и иностранные акции через API не оцениваются — для них
используется ручная цена.

## Как считается

- **Средняя цена** — себестоимость позиции (покупки с комиссиями) / количество.
  При продаже себестоимость списывается по средней цене.
- **Нереализованная прибыль/убыток** = стоимость позиции − себестоимость; % — к себестоимости.
- **Реализованная** = выручка от продаж − комиссии − списанная себестоимость.
- **Итого** = текущая стоимость + выручка от продаж − все покупки с комиссиями;
  % — к сумме всех покупок. Эта величина не зависит от метода списания (средняя/FIFO).
- **Чистые вложения** на графике = покупки с комиссиями − выручка от продаж на дату.
  Разрыв между линиями стоимости и вложений — прибыль/убыток на эту дату.
- Стоимость на прошлую дату — по цене закрытия MOEX (в выходные — по последней),
  сегодня — по текущей цене. Если истории котировок нет, используются цены сделок.
- Дивиденды, купоны и налоги не учитываются.

## Формат CSV

Экспорт рассчитан на Excel с русской локалью: разделитель `;`, десятичная запятая, UTF-8 с BOM.

```
Дата;Тикер;Операция;Количество;Цена;Комиссия
2025-01-15;SBER;Покупка;100;270,5;13,53
2025-06-02;SBER;Продажа;40;310;6,2
```

Импорт понимает разделители `;`, `,` и табуляцию, кодировки UTF-8 и Windows-1251,
даты `ГГГГ-ММ-ДД` и `ДД.ММ.ГГГГ`, операции «Покупка/Продажа» или `buy/sell`,
русские и английские заголовки (`date, ticker, side, qty, price, fee`) в любом порядке.
Файл без заголовка читается в порядке столбцов выше. При ошибках импорт не выполняется,
а сайт показывает номера строк.

## Структура

```
index.html        разметка
css/style.css     стили, светлая и тёмная тема
js/format.js      форматирование и разбор чисел и дат
js/portfolio.js   учёт: позиции, прибыль/убыток, история стоимости (чистые функции)
js/csv.js         экспорт и импорт CSV
js/moex.js        клиент MOEX ISS
js/charts.js      SVG-графики: кольцевая диаграмма и линия стоимости
js/app.js         интерфейс, хранение, обновление цен
tests/            юнит-тесты (node --test)
```

## Тесты

```
npm test
```

Нужен Node.js 18+. Тесты покрывают расчёты, CSV и разбор ответов MOEX ISS (с подменой сети).
